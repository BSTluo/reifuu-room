我希望制作一个2.5d的多人聊天游戏，我希望客户端使用vue和phaser，server使用nodejs。整个聊天游戏通过了注册登陆等用户验证的流程后可以创建个人的形象，而后进入聊天游戏。先给用户提供一个区域选择器，可以选择不同的洲（东南西北洲），选择后用户可以在洲内选择一个区块为初始位置。地图分为一个个区块，区块分为资源区块或者景观区块，资源区块内包含一些材料（木头，石头，矿物）等可挖掘的内容，当挖掘为空后，区块变为空地。可以用资源在空地或者景观区块创建自己的聊天室区块，当附近聊天室区块达到数量时，能够创建城镇，城镇可以建立与别人的城镇的传送门。聊天室内可以一起听歌，一起看视频，一起聊天和一起布置房间，请帮我组织团队策划这个游戏如何制作，策划完成后制作它。我希望整个游戏偏向二次元的像素中世纪画风,且视角是3/4视角。

我希望不同区域的玩家开始的时候只能看见周围几个区块的地图，后续跑图可以发现别的玩家，当发现别的玩家后，可以通过玩家信箱申请添加对方为好友，添加好友后可以随时打开地图传送到对方的区块内。除此之外玩家可以自己制作不同的交通工具前往别人的区块甚至跨洋去别的洲

另外跨大洋，和跨区块的用户可以通过寄飞鸽信，来发送信息，后续有玩家可以打通跨洋的交通渠道，或跨区块的交通渠道后，可以更快的传递消息。前期当没有合适的交通渠道的时候只能使用飞鸽传信来远距离传送信息，或是直接传送到对方的区块内和对方直接同区块交流

我希望房间还可以扩展，可以安装房间插件市场内的插件，并且为社区开发者提供一套扩展房间玩法的sdk方法，使得开发者能够制作一些房间道具，使用道具后可以多人打斗地主等增加房间玩法的插件之类的，请在当前阶段能够规划好足够的开发空间，在后面合适的时候增加sdk和说明文档

我希望每个人在没有受到邀请加入游戏的时候，出生点可以选择是随机无主的地块或者随机有人且公开的地块。每个人出生后的地块默认是不公开的，一个地块内在初次有人采集足够的资源建立房间后可以在房间配置内配置当前的地块是否公开，且后续这个地块属于这个人，每个人拥有的地块数量有上限，可以和别人组队来增加团队地块上限
