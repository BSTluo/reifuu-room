# Reifuu Chat 视觉风格指南

版本：v0.1　　日期：2026-09-01

---

## 1. 核心视觉定位

### 1.1 整体风格
- **类型**：二次元像素中世纪风格（Anime Pixel Art + Medieval）
- **视角**：3/4等距视角（Isometric），菱形tile布局
- **像素密度**：16-bit风格，统一像素密度避免视觉穿帮
- **参考游戏**：《符文工房》《牧场物语》《星露谷物语》

### 1.2 设计原则
1. **可读性优先**：像素艺术在小尺寸下保持清晰辨识度
2. **色彩鲜明**：二次元风格的高饱和度+中世纪的温暖色调
3. **风格统一**：所有资源遵循统一的像素网格和色板
4. **性能友好**：优化资源尺寸，适配Web游戏加载需求

## 3. 像素规范（Isometric 3/4视角）

### 3.1 基础分辨率

**角色（Character）**
- 基础尺寸：32x48 像素（宽x高）
- 站立状态：占据1个tile的中心位置
- 动画帧数：
  - 行走：4帧/方向（东南、西南、东北、西北四向）
  - 待机：2帧循环
  - 采集动作：3帧

**地形Tile（Isometric Diamond）**
- 标准tile：64x32 像素（菱形投影后的外接矩形）
- 网格坐标：前端使用gridToIso转换为屏幕坐标
- 高度层：
  - 地面层：z=0
  - 建筑/树木：z=1~3（最多3层叠加）
  - 顶部装饰：z=4

**建筑/物件（Building/Object）**
- 小型物件（资源节点）：64x64 像素
- 中型建筑（聊天室）：128x128 像素
- 大型建筑（城镇中心）：256x256 像素

### 3.2 等距视角要点

**深度排序**
- 使用y坐标+高度决定渲染顺序（前端已实现applyIsoDepth）
- 确保前景物体遮挡后景物体

**阴影表现**
- 轻微的投影阴影（深度x0.3透明度）
- 阴影方向：向东南偏移2-4像素

**遮挡处理**
- 当角色被建筑遮挡时，建筑半透明显示（alpha=0.5）
- 树木、高墙等需要设置透明切割线

## 4. UI组件风格

### 4.1 登录/注册界面
- **布局**：居中卡片式，背景为四大洲拼接的全景像素画
- **输入框**：羊皮纸纹理背景，深棕边框，圆角4px
- **按钮**：木质按钮质感，金色描边，悬停时微微发光
- **Logo**：游戏标题使用像素字体+中世纪装饰边框

### 4.2 游戏内HUD面板

**背包面板（Inventory）**
- 网格布局：5x8格子
- 格子尺寸：48x48像素
- 背景：深棕木板纹理
- 边框：金属铆钉装饰
- 物品图标：32x32像素，居中显示

**建造菜单（Build Menu）**
- 卡片式列表，每个聊天室模板一张卡片
- 卡片包含：预览图（64x64）、名称、所需资源图标x数量
- 资源不足时显示红色，足够时显示绿色

**聊天面板（Chat Panel）**
- 半透明深色背景（alpha=0.8）
- 消息气泡：羊皮纸色，头像+昵称+文字
- 输入框：底部固定，木质边框

**传送门面板（Portal Panel）**
- 地图缩略图显示已解锁的城镇位置
- 城镇图标：对应大洲的主题色
- 未解锁城镇：灰色剪影+问号

### 4.3 按钮与图标

**按钮样式**
- 主按钮：金黄底色，深棕文字，3px立体阴影
- 次按钮：深棕底色，米白文字，2px阴影
- 禁用状态：灰色，50%透明度

**图标设计**
- 尺寸：32x32像素（标准）、24x24（小图标）
- 风格：单色或双色，线条清晰
- 常用图标：
  - 背包：布袋子
  - 建造：锤子+木板
  - 地图：卷轴
  - 设置：齿轮
  - 传送：魔法阵

## 6. 技术规范

### 6.1 文件格式
- **精灵图**：PNG-8（256色），透明背景
- **Tilemap**：使用Tiled编辑器，导出JSON格式
- **UI切图**：PNG-24（带alpha通道）

### 6.2 命名规范
```
角色: char_{gender}_{part}_{state}_{frame}.png
  例: char_male_body_walk_0.png

地形: tile_{continent}_{type}_{variant}.png
  例: tile_east_grass_01.png

UI: ui_{component}_{state}.png
  例: ui_button_hover.png

物件: obj_{category}_{name}.png
  例: obj_resource_wood.png
```

### 6.3 资源优化
- 角色使用sprite sheet合并（减少HTTP请求）
- Tile set按大洲打包（4个atlas）
- UI图集单独打包（1个atlas）
- 目标：Phase 1总资源<2MB，Phase 2-3各<3MB
