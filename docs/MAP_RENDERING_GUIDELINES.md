# 地图渲染设计指南

版本：v1.0　　日期：2026-09-01

---

## 地块渲染原则

### 无缝衔接设计

**核心要求**：地块与地块之间不应有明显的视觉边界，整个地图应呈现为连续的、自然的世界。

**实现要点**：

1. **Tilemap连续性**
   - 使用统一的Tilemap，而非为每个区块单独渲染
   - 区块（Chunk）仅作为逻辑单位，不应在视觉上显示边界线
   - 地形tile应自然过渡，无明显接缝

2. **避免的做法**
   - ❌ 不要在区块边界绘制线条或边框
   - ❌ 不要在区块切换时出现视觉断层
   - ❌ 不要使用不同的背景色区分区块

3. **建议的做法**
   - ✅ 使用连续的tile拼接，让地形自然流动
   - ✅ 区块边界处的tile应与相邻区块的tile协调
   - ✅ 资源节点、建筑等元素跨区块时保持视觉一致性
   - ✅ 仅在debug模式下显示区块边界（可选）

4. **地块所有权可视化**
   - 地块所有权信息通过其他方式呈现：
     - 建筑外观（已建造的区块）
     - 点击/悬停时显示信息面板
     - 小地图上使用颜色标记
   - 不要在游戏主视图中用边界框标记所有权

5. **技术实现**
   ```typescript
   // WorldScene中的地图渲染
   // 使用单一大地图，而非多个区块拼接
   this.map = this.make.tilemap({
     data: combinedMapData, // 所有区块合并后的数据
     tileWidth: 64,
     tileHeight: 32,
     width: totalWidth,
     height: totalHeight
   });
   
   // 区块仅用于逻辑管理（位置同步、资源加载等）
   // 不影响视觉渲染
   ```

6. **区块切换过渡**
   - 玩家移动跨越区块时应感受不到任何视觉变化
   - 相机跟随应平滑，不因区块切换而跳动
   - 资源加载/卸载应在后台进行，不影响视觉连续性

---

## Debug模式

开发和调试时，可以选择性地显示区块边界：

```typescript
if (DEBUG_MODE) {
  // 使用半透明网格线显示区块边界
  this.debugGraphics.lineStyle(1, 0xff0000, 0.3);
  // 绘制区块边界...
}
```

正式游戏中应完全隐藏这些debug信息。

---

## 视觉连续性检查清单

在实现地图渲染时，确保：

- [ ] 地块之间无可见边界
- [ ] 地形过渡自然
- [ ] 区块切换无视觉跳跃
- [ ] 相机移动平滑
- [ ] 资源节点分布看起来自然
- [ ] 建筑放置不受区块边界影响
- [ ] 玩家移动跨区块时无卡顿

---

**原则总结**：区块（Chunk）是服务器端的逻辑概念，用于管理数据和同步。在客户端视觉层面，应该呈现为一个无缝连接的、连续的世界。
